# 🎬 Netflix Analytics Dashboard

An interactive data visualization dashboard built with **Streamlit**, **Pandas**, and **Matplotlib** to explore and analyze Netflix's global content catalog.

---

## 📌 Project Overview
This project processes raw Netflix catalog records (`netflix_titles.csv`) to uncover trends in content formats, release timelines, global production, and popular genres. It provides an intuitive web interface for data exploration and visual reporting.

---

## ✨ Features
* **Dynamic Filtering:** Filter dashboard metrics by content type (Movies vs. TV Shows) using the interactive sidebar.
* **Content Distribution:** Visual breakdown of platform titles categorized by format.
* **Top 10 Producing Countries:** Ranking of countries contributing the highest volume of content.
* **Catalog Growth Analysis:** Line chart visualizing content additions over the years.
* **Top 10 Genres:** Exploded multi-genre analysis highlighting dominant categories.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework:** Streamlit
* **Data Manipulation:** Pandas
* **Data Visualization:** Matplotlib, Streamlit Charts
